# Bluetooth Media Remote

a small device to control media playback over bluetooth

## features

- bluetooth conectivity (esp32)
  - uses the [HijelHID_BLEKeyboard library](https://github.com/HijelHub/HijelHID_BLEKeyboard)
- controls
  - play/pause
  - skip forward
  - skip backward
  - volume up
  - volume down
  - pairing mode (hold play/pause and vol up for 5 seconds)

## future features

- rgb led from button pcb for status
- battery
  - bms
  - usbc charging
- 3d printed housing probably
